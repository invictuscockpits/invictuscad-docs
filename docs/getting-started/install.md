# Install Cahaba Studio

## What you need

- Windows 10 or 11, 64-bit
- A graphics card with OpenGL support (any recent integrated or dedicated GPU)
- An internet connection to start the trial or activate a license. After that, Cahaba Studio runs
  offline.

## Install

1. Download the installer from [cahaba3d.com/download](https://cahaba3d.com/download).
2. Run it and follow the prompts.
3. Start Cahaba Studio from the Start menu.

The first time it starts, Cahaba Studio starts your 30-day free trial by itself. If you've already
bought a license, enter the key in **☰ › Help › License**. See
[Free trial and activation](trial-and-activation.md).

Next: [Your first part](first-part.md).

## Coming from InvictusCAD

Cahaba Studio is the new name of InvictusCAD. Updating from InvictusCAD (it offers the update
itself, or run the Cahaba Studio installer) replaces it: the installer removes InvictusCAD, and the
first time Cahaba Studio starts it brings your license, settings, tool libraries, footprints and
backups across. Your `.ivc` projects open as before.

## Updating

Install a newer version over the old one; your settings and files are kept. Your license runs every
version released while your updates are current. See
[How licensing works](../license/how-licensing-works.md).

## Uninstalling

Uninstall from Windows **Settings › Apps**. Your projects, and your settings, libraries and backups
in `%LOCALAPPDATA%\CahabaStudio`, are left in place. To move your license to another computer
first, see [Move to another computer](../license/move-computers.md).
