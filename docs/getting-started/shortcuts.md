# Keyboard Shortcuts

## Everywhere

| Keys | Action |
|---|---|
| ++ctrl+n++ / ++ctrl+o++ | New / Open |
| ++ctrl+s++ / ++ctrl+shift+s++ | Save / Save As |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo |
| ++ctrl+k++ | Search for a tool |
| ++f++ or ++home++ | Fit the view |
| ++ctrl+b++ | Show or hide the browser |
| ++ctrl+l++ | Show or hide the command log |
| ++delete++ | Delete the selection |
| ++f2++ | Rename the selected item in the browser |
| ++esc++ | Step back: close the card, cancel the shape, finish the sketch, clear the selection |
| ++ctrl+f12++ | Capture the window as an image |

## Modeling

| Keys | Action |
|---|---|
| ++e++ | Extrude |
| ++h++ | Hole |
| ++m++ | Measure |

## In a sketch

| Keys | Action |
|---|---|
| ++l++ | Line |
| ++r++ | Rectangle |
| ++c++ | Circle |
| ++a++ | Arc (3-point) |
| ++shift+a++ | Center arc |
| ++g++ | Polygon |
| ++s++ | Spline |
| ++p++ | Point |
| ++o++ | Offset |
| ++d++ | Dimension |
| ++x++ | Construction: toggle the selected curve, or draw new geometry as construction |
| ++ctrl+g++ / ++ctrl+shift+g++ | Group / Ungroup |
| ++tab++ | Keep the typed value and move to the next field |
| ++enter++ | Place the shape; finish a spline; apply a value |
| ++alt++ + drag | Move one point inside a group |
| ++shift+++click | Offset one curve instead of the chain |
| ++e++ | Finish the sketch and extrude it |

## Mouse

| | |
|---|---|
| Middle-drag | Pan |
| Right-drag, or ++shift++ + middle-drag | Orbit |
| Wheel | Zoom at the cursor |
| Click | Select (++ctrl++ or ++shift++ to add) |
| Double-click in the browser | Edit the item |
