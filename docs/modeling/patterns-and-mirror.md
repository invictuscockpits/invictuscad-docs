# Patterns and Mirror

Copy features (extrude, revolve, sweep, loft, hole) or whole bodies:

- **Rectangular**: in one or two directions
- **Circular**: around an axis
- **Along a path**: following a curve
- **Mirror**: across a plane

Patterns are associative: change the original or the pattern's count and spacing, and the copies
follow. Sketches have their own rectangular, circular and path patterns, which keep each copy's
constraints.
