# FAQ

**Does InvictusCAD need the internet?**
Only to start the trial, activate, and check in about once a month. It works offline otherwise.

**Is there a subscription?**
No. You buy a license once. Renewing updates is optional.

**What happens when my updates end?**
Nothing stops working. See [How licensing works](../license/how-licensing-works.md).

**Can I use it on my laptop and my shop PC?**
Yes, on 2 computers at a time. See [Move to another computer](../license/move-computers.md).

**Can I use it for commercial work?**
Yes.

**Does InvictusCAD upload my designs?**
No. Your files stay on your computer.

**What file formats can it read and write?**
Projects are `.ivc` files. It imports SVG, DXF, Illustrator and PDF drawings into sketches and
exports DXF and SVG for cutting. See [Importing 2D drawings](../sketching/import.md) and
[Flat parts and nesting](../making/flat-parts-and-nesting.md).

**Does it run on Mac or Linux?**
Not yet; it's Windows only for now.
