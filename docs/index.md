# InvictusCAD

InvictusCAD is parametric CAD for Windows, built for people who make real parts: sketch,
constrain, model, assemble, and send flat parts to the laser or router.

- **New here?** [Install InvictusCAD](getting-started/install.md) and start the
  [30-day free trial](getting-started/trial-and-activation.md).
- **Learn the basics:** [Sketches and constraints](sketching/sketches-and-constraints.md),
  then [features](modeling/features.md).
- **Bought a license?** [Activate it](getting-started/trial-and-activation.md#activate-a-license),
  or [move it to another computer](license/move-computers.md).
- **Using Claude?** [Drive InvictusCAD over MCP](automation/mcp.md).

## How InvictusCAD thinks

- **Everything is parametric.** Features remember their inputs. Change a dimension and the model
  rebuilds from its history.
- **Type lengths the way you think.** `1/4"`, `6mm` and `wall + 2` all work anywhere a length goes.
  See [Units and expressions](getting-started/units-and-expressions.md).
- **References are stable.** Faces and edges are named after the features that made them, so later
  features keep working when you edit earlier ones.
- **Every change is undoable.** Edit > Undo steps back one command at a time, including changes
  made by an AI assistant.
- **Your files are yours.** An `.ivc` file is an open zip of JSON design intent plus geometry.
