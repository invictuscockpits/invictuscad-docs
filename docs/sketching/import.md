# Importing 2D Drawings

Bring vector artwork into a sketch from **SVG, DXF, Adobe Illustrator (.ai) or PDF** files.
Drag the file onto InvictusCAD, or import it from the menu.

A placement card shows a preview and lets you set the width and position before the geometry
lands. Imported paths are joined into connected sketch geometry, ready to constrain and extrude.

!!! note "Current limits"
    Filled (hatch) regions aren't imported, DXF layers come in together, and SVG text needs to be
    converted to outlines in the program that made it.
