# Text in Sketches

Sketch text uses any installed font and extrudes like other geometry, keeping the holes in letters
such as O and A.

- Size by cap height or font size (points are supported), with angle, alignment, bold and italic,
  and several lines.
- Layout controls like a design program's character and paragraph panels: tracking, kerning,
  leading, scale, baseline shift, letter rotation, all caps, vertical text, and text on a path.
- The text's position point takes constraints, so it can be dimensioned like anything else.
- Double-click text to edit it.

## Convert to outlines

**Convert to Outlines** turns text into ordinary lines and splines, for when you want to edit
letter shapes or send them somewhere that doesn't have your font.
